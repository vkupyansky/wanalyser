# WAnalyser

Telegram-бот для поиска предметов Warframe Market и отслеживания цен. Показывает предложения продавцов в игре, поддерживает поиск по русскому названию, персональные подписки, профиль и реферальный баланс.

## Запуск

Нужны Python 3.12-3.14, [uv](https://docs.astral.sh/uv/), PostgreSQL, Redis и публичный HTTPS reverse proxy. Проект использует webhook, сервер слушает только `127.0.0.1:8080`.

```sh
uv sync --frozen
uv run --frozen python scripts/init_env.py
```

Заполните созданный `.env`. Его права должны оставаться `0600`.

| Параметр | Назначение |
| --- | --- |
| `BOT_TOKEN` | Токен вашего бота от BotFather |
| `BOT_NAME` | Имя этого бота без `@` |
| `PG_DSN` | Строка подключения к выделенной PostgreSQL БД |
| `REDIS_URL` | Адрес Redis для ограничения частоты запросов |
| `BASE_WEBHOOK_URL` | Публичный HTTPS origin без завершающего `/` |
| `WEBHOOK_SECRET` | Внутренний секрет, однократно созданный `init_env.py` |

Все параметры обязательны. Не используйте рабочие credentials для тестов. Для удалённого PostgreSQL настройте проверку TLS-сертификата через параметры DSN.

Создайте отдельную БД и роль, затем подготовьте таблицы и запустите бот:

```sh
uv run --frozen --env-file .env python setup.py
uv run --frozen --env-file .env python main.py
```

Reverse proxy должен передавать `/webhook` на локальный сервер без удаления заголовка `X-Telegram-Bot-Api-Secret-Token`. В BotFather включите inline mode для поиска из других чатов. После `/start` администратор назначается владельцем БД через поле `users.admin`; права проверяются повторно при административных действиях.

## Данные и ограничения

PostgreSQL хранит Telegram ID, имена, подписки и историю статуса premium. Redis хранит счётчики запросов. `dictionary.json` содержит каталог игровых предметов. Дампы, списки пользователей и `.env` в репозиторий не входят.

Входящие сообщения и уведомления проходят через Telegram; цены запрашиваются у Warframe Market. Топы в интерфейсе временно отключены. Существующие тексты premium ссылаются на ручное оформление через Boosty; автоматического платёжного шлюза нет.

Проект использует API Warframe Market v1 для поиска и уведомлений и v2 для обновления каталога. Работа с актуальными внешними API и полный цикл Telegram/PostgreSQL/Redis требуют отдельной проверки с новыми credentials. Состояние после перезапуска для черновиков и защиты от повторных уведомлений не сохраняется.

## Проверки

```sh
uv run --frozen python scripts/check.py
```

Команда проверяет синтаксис с warnings as errors, критические ошибки Ruff, изолированные регрессионные тесты `pytest -W error` и известные уязвимости установленных зависимостей. Она не отправляет сообщения и не подключается к рабочей БД. Подробности и ограничения: [STATUS.md](STATUS.md).
